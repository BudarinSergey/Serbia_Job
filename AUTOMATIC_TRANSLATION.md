# Автоматический перевод: MyMemory

Активный провайдер в .env: TRANSLATION_PROVIDER=mymemory.
Карта, email, регистрация и API-ключ не используются. Прямой официальный REST API:
https://api.mymemory.translated.net/get (только q и langpair).
Google, Azure и локальная модель в этом режиме не вызываются.

Исходный язык определяется локально среди сербского, английского и русского;
сербская латиница может определяться как хорватский/боснийский и приводится к sr.
На коротких и смешанных фразах определение может ошибаться. Неуверенный результат
блокируется. Сербский оригинал сохраняется, для него нужен только запрос sr|ru.
Английские фразы переводятся на sr и ru. Сербский вывод приводится к латинице.
Работодатель, место и неизвестные факты не переводятся/не придумываются.

Проверенный вручную словарь имеет приоритет. Машинные результаты хранятся в
PostgreSQL translation_cache отдельно от других сервисов. Ручные исправления
не затирают исходный машинный результат. Наличие ответа API не гарантирует
точный смысл профессиональной терминологии.

Лимиты: максимум 500 байт UTF-8 в q; длинные фразы остаются на проверке без
обрезания. Бесплатный анонимный сервис ограничен 5000 символами в день.
Локальный счётчик mymemory_usage использует дату UTC и отдельные транзакции:
неудачные/неопределённые запросы тоже учитываются, откат очереди не сбрасывает расход.
Запросы из других программ с того же IP счётчик не видит. При quotaFinished,
responseStatus 429 или HTTP 429 сохраняется пауза 24 часа. При прочих ошибках
новые обращения останавливаются до следующего цикла. Нет обхода лимитов и
платного запасного сервиса. Кэш работает даже при остановленных запросах.

Проверяются HTTP, responseStatus, quotaFinished, пустой/служебный ответ и числа.
--prepare-telegram подготавливает очередь без отправки; обычный main.py переводит
перед публикацией. Предпросмотры используют кэш без внешних запросов.

2026-10-01: три реальные вакансии успешно переведены (четыре API-запроса),
машинные ответы сохранены. Для трёх заголовков добавлены вычитанные формулировки
в ручной словарь. Тестовые сообщения в Telegram не отправлялись.

Исправление 2026-10-01: проблемы отдельных фраз (неуверенное определение языка,

## Обновление 02.10.2026

Исходный язык MyMemory фиксирован: сербский (латиница), запрос sr|ru.
Сербская часть сохраняется из оригинала; автоматическое определение языка отключено.
Это заданное предположение, а не проверка: английские заголовки требуют отдельного
проверенного перевода, если результат sr|ru не подходит.
Название остаётся обязательным для перевода. Дополнительный текст образования
длиннее 500 UTF-8 байт не отправляется переводчику: карточка содержит указание
смотреть оригинал. Короткие соседние пункты сохраняются, исходные данные в базе
не изменяются. Слишком длинное название по-прежнему требует проверки.


### Исходное название при недоступном переводе

Если перевод названия недоступен, карточка публикуется с исходным названием
один раз, без подстановки выдуманного перевода. Перевод по-прежнему выполняется,
когда он доступен. Это заменяет прежнее требование обязательного перевода названия.
Ограничения по длине всего сообщения, проверки других полей, дублей и истории
отправок сохраняются. Ожидающие записи обновляются обычной подготовкой очереди
в следующем цикле. Уже опубликованные сообщения не отправляются повторно.


### Упрощённое образование

В карточке выводится только значение образования. Элементы bound=max полностью
исключены; для остальных не добавляются мин./макс. и пометки обязательности.
При отсутствии перевода используется исходное значение. Исходные данные и
квалификаторы в PostgreSQL сохраняются для аудита. Если осталось только max,
в карточке образование обозначается как не указанное.
